# My Notes App

A simple web-based Notes App that allows users to create, edit, and delete notes.

## Features

- Add a new note
- Edit an existing note
- Delete a note
- Prevent empty notes
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Jest
